# STAR HOME — Синхронизация Cloud ↔ Local Gateway

Cloud — UX, права, аудит, очередь команд. Дом работает без интернета на локальном контроллере.

## Канал

- Исходящее: local выполняется сразу; не-local кладётся в очередь `gatewayCommands` с `commandId`.
- Шлюз забирает очередь (`kind: pull`) и подтверждает (`kind: ack`). Повторный ack не меняет state.
- Входящее: `kind: state` → NormalizedState. MQTT в интернет не открываем.
- Нет канала — `confirmed: false`, команда может быть `QUEUED`.

## Конфликт

Истина — последнее **подтверждённое** состояние адаптера. Облако не затирает локальный контроллер догадками.

seq live монотонный на объект. Меньший seq отбрасывается.

## Офлайн

Шлюз OFFLINE (не local): команда не успех. lastSeen не прячется.

Local adapter (демо и встроенный контур) может подтвердить LOW/MEDIUM и openers, как существующие ворота.
