## 2. Живая проверка

API на живом Postgres, Next dev на :3456, `curl` и браузер.

| Запрос | Ожидание | Факт |
| --- | --- | --- |
| Вход с `Origin: https://evil.example` | 403 | 403 «Запрос отклонён» |
| Открыть ворота с cookie администратора, `Sec-Fetch-Site: cross-site` | 403 | 403 |
| Удалить объект с чужим `Origin` | 403 | 403 |
| Выгрузка журнала со своего origin | 200 CSV | 200 `text/csv` |
| Вызов API без подписи | 401 | 401 |
| Подписанный вызов API пятиминутной давности | 401 | 401 |
| Тот же вызов с текущим временем | 200 | 200 |
| Заголовки страницы | см. ниже | все на месте, `X-Powered-By` нет |

Заголовки: `X-Frame-Options: DENY`, `Content-Security-Policy: frame-ancestors 'none'; base-uri 'self'; form-action 'self'; object-src 'none'`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `Permissions-Policy: camera=(), microphone=(), geolocation=(), payment=()`, `Cross-Origin-Opener-Policy: same-origin`, `Cache-Control: no-store` для `/api/*`.

В браузере: вход администратора, выгрузка журнала кнопкой, вход жителя, переключение режима кликом. Проверка origin настоящим действиям не мешает.

## 3. Найдено и закрыто в Phase F

| # | Проблема | Риск | Исправление |
| --- | --- | --- | --- |
| F1 | Защита от CSRF держалась только на `SameSite=lax` | Старые браузеры и поддомены | `server/same-origin.ts` + `proxy.ts`: изменяющие запросы к `/api/*` с чужим origin → 403 |
| F2 | Подписанный вызов Next → API можно было повторить бесконечно | Повтор перехваченного запроса на loopback | Метка времени `at` в подписанном теле, окно ±60 с (`server/internal-secret.ts`) |
| F3 | В production оба процесса молча брали внутренний секрет по умолчанию | Подделка вызовов API, live-токенов | `internalSecret()` бросает ошибку без `STAR_HOME_INTERNAL_SECRET` в production |
| F4 | Истёкшее membership семьи позволяло переключать режим дома и получать live-токен | Бывший член семьи управляет домом | `findMembership` не возвращает истёкшие membership, `liveToken` проверяет срок |
| F5 | Не было заголовков против встраивания страницы и подмены типа | Clickjacking на «Открыть ворота» | Заголовки в `next.config.ts` |
| F6 | Повторные отказы могли вытеснить настоящие записи из окна журнала | Сокрытие следов | Не больше 10 записей об отказе на пользователя и метод в минуту |
| F7 | Вход жителя и отказ сотруднику объекта записывались как «Вся компания» | Администратор объекта не видел их в журнале | Место берётся из membership человека |

## 4. Осталось (не блокирует, решение за владельцем)

| # | Что | Почему не сделано сейчас |
| --- | --- | --- |
| R1 | Полноценный CSP для скриптов (`script-src` с nonce) | Next dev и inline-скрипты гидрации требуют nonce-инфраструктуры. Сейчас стоит CSP без `script-src` |
| R2 | IP из `x-forwarded-for` без доверенного прокси можно подделать | Решается конфигурацией прокси при деплое. Поле справочное, в правах не участвует |
| R3 | Cookie живёт 14 дней без продления по активности | Отзыв работает через `sessionVersion`. Срок — продуктовое решение |
| R4 | Сотрудник корпуса может открыть общие ворота объекта | Вопрос из Phase D. Сейчас общая инфраструктура доступна корпусу |
| R5 | Лимит входов держится на логине, не на IP | Защищает от подбора пароля одного логина, не от перебора логинов с одного адреса |
