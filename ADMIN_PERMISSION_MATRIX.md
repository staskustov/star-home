# STAR HOME — Admin Permission Matrix

Статус: **проект матрицы. Источник истины после реализации — `apps/web/src/server/rbac/policy.ts` в процессе API.**

## 1. Формат права

```
<group>.<action>[.<object>]
```

Базовые действия: `view`, `create`, `edit`, `delete`, `manage`.

`manage` не является шаблоном «всё сразу». Это конкретное право на опасную операцию группы. Опасные действия вынесены в отдельные ключи, чтобы `edit` не открывал их случайно.

Право всегда проверяется вместе со scope membership. В таблицах scope роли по умолчанию:

| Метка | Смысл |
| --- | --- |
| ● | в пределах scope membership (компания, объект, корпус, единица) |
| S | только свои записи (SELF) |
| — | нет права |

Критические права (в аудит пишутся и успех, и отказ) помечены `!`.

## 4. Правила назначения

Жёсткие правила. Их нельзя ослабить через матрицу:

1. Назначать можно только роль с рангом **не выше своего**. OBJECT_ADMIN — только **ниже своего**.
2. SUPER_ADMIN назначает только SUPER_ADMIN.
3. Scope назначаемой membership должен лежать **внутри** scope назначающего.
4. Нельзя менять роль, scope или статус самому себе.
5. Нельзя заблокировать или удалить последнего активного COMPANY_ADMIN компании.
6. «Команда» не назначает RESIDENT, FAMILY_MEMBER, GUEST. Для них есть «Жители».
7. Изменение роли, scope или статуса увеличивает `sessionVersion` пользователя.

## 5. Переопределения матрицы

Системная матрица задаётся кодом (`policy.ts`). Компания может сузить или расширить права роли в пределах **потолка**: права, доступные роли по рангу.

- SA матрицу не переопределяют.
- CA не может снять себе `roles.edit`, `users.role.assign`, `users.block`, иначе компания потеряет управление.
- Права `payments.pay`, `home.*`, `guest.*` не переносятся на сотрудников.
- Каждое изменение пишется в журнал с полями `from` и `to`.

Если переопределения не нужны в первой версии, страница «Роли и права» показывает матрицу только для чтения. Решение — в вопросах к подтверждению.

## 6. Где проверяется

| Слой | Что делает |
| --- | --- |
| API, `decide.ts` | Решение «можно ли». Единственное место |
| API, `methodPolicy` | Для каждого RPC: право и способ получить target из input |
| API, доменные функции | Инварианты данных: чужой объект, занятая единица, последний админ |
| Next `guardPath` | Перенаправление со страниц без права. Удобство, не защита |
| UI | Показывает только разрешённые разделы и кнопки по списку от сервера |
