# STAR HOME — Design System

Характер: премиальная недвижимость, спокойный цифровой сервис, ясность smart home.

Ориентир — минимализм, воздух, иерархия, крупная типографика, понятное действие. Это не копия интерфейсов Apple и не копия экранов `siyanie` или админки `star-hub`.

Не использовать: неон, киберпанк, дешёвый глянец, перегруженный dashboard, разноцветные карточки, декоративный шум, тяжёлую библиотеку анимаций.

Принцип интерфейса: меньше экрана, больше действий.

## 1. Цвет

Светлая тема — основная. Тёмный режим в Phase 1 не обязателен. Если появится позже, те же роли токенов, другие значения.

| Токен | Значение | Роль |
| --- | --- | --- |
| `bg` | `#F6F4F0` | Тёплый фон страницы |
| `surface` | `#FFFFFF` | Карточки и форма |
| `surface-muted` | `#EFECE6` | Вторичные плашки |
| `ink` | `#1A1A1A` | Заголовки |
| `graphite` | `#3F3D39` | Основной текст |
| `muted` | `#6F6B64` | Подписи |
| `line` | `#E4E0D8` | Границы |
| `accent` | `#1F3A34` | Единственный фирменный акцент: кнопки, активное состояние |
| `accent-contrast` | `#F7F5F1` | Текст на акценте |

Статусы только для смысла, маленькой точкой или коротким словом:

| Токен | Значение |
| --- | --- |
| `success` | `#2F6B4F` |
| `warning` | `#8A5A12` |
| `danger` | `#8E2F2F` |
| `info` | `#3E5550` |

Акцент `siyanie` `#3b82f6` не переносится. Тёмный фон админки STAR OS не переносится.

## 2. Типографика

Семейство: `Inter`, запасной стек `system-ui, sans-serif`.

| Роль | Размер | Насыщенность |
| --- | --- | --- |
| Марка STAR HOME | 13px, tracking широкий | 600 |
| Заголовок экрана | 34–44px | 560 |
| Приветствие | 28–34px | 560 |
| Секция | 20–22px | 560 |
| Тело | 16–17px | 430 |
| Подпись | 13–14px | 450 |

Короткие фразы. Крупные числа температуры и сумм. Много пустого поля.

## 3. Форма и пространство

Базовая сетка 8px.

- Поле ввода: высота 52px, радиус 14px, граница `line`, фон `surface`.
- Главная кнопка: высота 52px, радиус 14px, фон `accent`.
- Карточка: радиус 20px, фон `surface`, без тяжёлой тени. Допустима тень `0 1px 2px` очень низкой непрозрачности или одна граница.
- Отступы экрана: 20px на узком телефоне, 32px от 768px.
- Ширина формы входа: до 400px, по центру.

## 4. Движение

Длительность 180–220ms, easing `cubic-bezier(0.2, 0, 0, 1)`.

Допустимо: fade, смена статуса, skeleton, нижний лист на мобильном.

Без Framer Motion, пока хватает CSS.

## 5. Компоненты

Общие, без знания конкретного посёлка:

`AppShell`, `Header`, `Sidebar`, `BottomNavigation`, `LoginForm`, `ObjectSwitcher`, `LifeModeSwitcher`, `HomeStatus`, `SecurityStatus`, `QuickActions`, `VisitorCard`, `PaymentCard`, `AIBar`, `StatusBadge`, `MetricCard`, `EventList`, `ObjectCard`, `AdminStats`, `AdminSidebar`, `ResponsiveContainer`.

Компонент принимает данные и подписи. Он не содержит строк «КП Сияние» и не выбирает ветку по `ObjectType`, кроме отображения уже готовой подписи.

## 6. Экран входа

Марка по центру: STAR HOME.

Поля: логин, пароль. Кнопка «Войти». Ссылка «Забыли пароль?».

Нет баннеров, выбора посёлка, названия объекта, рекламы.

Desktop: компактная колонка по центру на тёплом фоне.
Mobile: та же колонка на всю ширину с боковыми полями, без второй композиции.

Фоновое фото не требуется.

## 7. Дом жителя

Mobile-first. Desktop использует ту же систему, контент в колонке читаемой ширины, нижняя навигация на широком экране может стать левой. Это одна оболочка `AppShell`, не второй продукт.

Порядок:

1. STAR HOME
2. Приветствие по времени суток и имя
3. Объект и единица одной строкой
4. Три режима: Дома, На работе, В отпуске
5. Статус дома, температура, влажность, защита
6. Быстрые действия: Открыть ворота, Гости, Охрана, Оплатить
7. Сегодня: гость, счёт, событие
8. Полоса AI STAR HOME: «Что сделать?»

Нижняя навигация: Главная, Доступ, AI, Сервис, Профиль.

В Phase 1 пункты кроме «Главная» открывают спокойную заглушку раздела, без бизнес-логики.

## 8. Администратор

Desktop-first. Отдельная композиция `AppShell`, те же токены.

Слева: Обзор, Объекты, Жители, Доступ, Охрана, Заявки, Платежи, Устройства, AI, Настройки.

Сверху: STAR HOME, компания, выбор объекта.

На обзоре: числа объекта, события доступа, состояние систем, кнопка «Добавить объект».

Планшет сужает сайдбар до иконок или верхней панели. Телефон администратора в Phase 1 не является главным макетом, но не должен ломать чтение: одна колонка, сайдбар прячется.

Раздел «Объекты» показывает карточки разных типов из фикстуры. Кнопка добавления есть. Мастер создания в Phase 1 не проводится до конца: цель фазы — утвердить вид, не Object Builder.

## 9. Проверка ширины

Обязательные ширины для Phase 1: 320, 375, 390, 393, 430, 768, 1024, 1280, 1440, 1920.

Житель проверяется сначала на 390. Администратор — сначала на 1440.
