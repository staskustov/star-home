# STAR HOME — PWA

Одно веб-приложение ставится на телефон как STAR HOME. Отдельные native-приложения на первом этапе не делаются.

Манифест `star-hub` («STAR OS», тёмная тема, `start_url: /admin`) не используется.

## 1. Manifest

Файл: `manifest.webmanifest`.

```json
{
  "name": "STAR HOME",
  "short_name": "STAR HOME",
  "display": "standalone",
  "start_url": "/",
  "scope": "/",
  "background_color": "#F6F4F0",
  "theme_color": "#F6F4F0",
  "lang": "ru"
}
```

Иконки: 180, 192, 512, maskable 512. Знак — слово или простой архитектурный знак STAR HOME, без символики одного посёлка.

`display: standalone`. Дополнительно `minimal-ui` только как fallback.

Установка: Android, iOS/iPadOS, desktop. HTTPS обязателен вне localhost.

## 2. Service worker

Кэшируется оболочка:

- HTML каркас входа и дома;
- CSS и шрифт;
- иконки и статическая графика;
- последнее подтверждённое состояние экрана дома.

Не кэшируется как истина:

- открытие ворот и замков;
- оплата;
- создание пропуска;
- тревога и команды устройствам;
- ответы AI о фактах.

Пока API не подтвердил действие, интерфейс показывает: «Не удалось подтвердить выполнение.» Фраза «Ворота открыты» без ответа сервера запрещена.

Сеть сначала для API. Оболочка — cache-first для статики.

## 3. Установка и обновление

На поддерживаемых браузерах — свой тихий install prompt после того, как человек уже вошёл и увидел дом. Не на первом кадре логина.

Новая версия оболочки применяется после подтверждения, без обрыва незакрытого действия. Паттерн обновления service worker из админки `star-hub` можно изучить, код не копировать: другой scope и другое имя.

Web Push подключается вместе с уведомлениями, не в Phase 1. Критические события позже идут в push, охрану и audit.

## 4. Phase 1

В визуальной фазе достаточно заготовки:

- manifest с именем STAR HOME и `standalone`;
- иконки;
- регистрация service worker, который кэширует статику и не подтверждает действия.

Проверка установки на устройстве — часть отчёта Phase 1, если среда позволяет. Боевой offline-режим устройств не имитируется успехом.
